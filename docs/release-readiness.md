# 首次公开发布前检查

本清单记录 2026-11-06 首版源码交付的整理范围与验证边界，不是官方认证或完整安全审计。源码提交与远程交付状态以 Git 历史和关联 Issue #1 为准；上传源码不等于发布稳定版、npm 包或 GitHub Release。

## 已完成

- 保留包名 `@local/intent-canvas`、存储域 `intent_canvas_shared`、既有路由及会话文档 id，未迁移或删除用户数据。
- Host 去除机器绝对路径，改用标准 ESM 和 peer 声明；按当前官方 app-boot 的 peer-aware 解析机制编写。
- 清单限定 DSH `0.2.2-rc.1`，声明 Node.js 22+、MIT、仓库和问题入口，保留 `private: true` 防止误发 npm。
- 去除无条件关闭已有域句柄的恢复捷径，只清理当前实例拥有的句柄；去除未使用的 `webServer` 强依赖。
- 「填入」改用会话 Slot 的 `inputActions`，不扫描宿主 DOM、不覆盖草稿选区；没有接口时只复制到剪贴板。
- 主画布标签通过官方 locale register/bind 读取，并订阅字典 revision；英文插件标题采用 sentence case。
- 所有 pending 类型的批准均要求可信 human 作者，含自定义类型。拒绝仍可由 AI 提交。
- 新增 Host 适配、域生命周期、非默认 pending 批准、输入插入与拒绝回归测试。
- 使用 Node.js 24.21.0 执行全套测试和脚本语法检查；最终数量与结果见提交关联 Issue 的验证记录。系统 Node.js 20.18.1 曾通过早期用例，但不是声明支持版本。
- npm pack dry-run 核对运行入口、补丁、图标、双语元信息与许可；临时截图未纳入包。
- 源文件常见令牌/私钥模式扫描未命中；这不等于专业秘密扫描，也未证明全部 Git 历史不存在敏感数据。
- 补齐贡献、安全、MIT、换行规则与 Node.js 22/24 CI 配置；CI 尚未在 GitHub 执行。

## 正式发布前必须完成

1. **分发许可**：实际引入第三方代码或素材时，核对适用许可证并保留必要声明。开发过程中的界面与交互参考不属于运行时依赖；项目 MIT 许可仅覆盖有权许可的部分。
2. **真实加载**：在目标 DSH 中重新安装/重载后验证标准 ESM 依赖解析。当前测试使用 DSH 边界桩，不证明真实 Loader 的激活结果。本轮没有重新安装、重启或刷新用户正在使用的插件。
3. **真实交互**：绘图、擦除、撤销、重做、重启持久化、两个会话隔离、填入/发送、复制/粘贴、PNG、批注及人类批准逐项验收。不得用槽位存在代替功能验证。
4. **主题与语言验收**：控件浮层与工具提示已接入官方主题 token，通知、导航和画布摘要经 locale 绑定；仍须做浅深色截图、切换语言的真实页面验收。UI 字典随动态 Client 内置并通过官方 locale 服务注册，避免额外资源请求；插件管理元信息继续通过导出的 locale JSON 提供。
